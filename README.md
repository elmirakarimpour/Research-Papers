## Research theme

These research works ask under which conditions a learned security system can be trusted: when data cannot be centralized and attack classes are rare (TwinFL-R), and when multiple detectors and language-model agents may agree for the wrong reasons or act on unsupported claims (CARE-IPS). My MSc thesis, currently in progress, approaches the same theme through representation learning for insider threat detection from user behavior sequences.
